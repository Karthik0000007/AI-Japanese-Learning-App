# Screenshots

Placeholders referenced from the main README. Record them from the Docker
stack (`docker compose up --build`, with `--profile ai` for the tutor shot)
and save them here with exactly these names:

| File | What to capture |
|---|---|
| `flashcards.gif` | A short review: reveal a card, grade it, next card (5–10 s, under 5 MB) |
| `dashboard.png` | The Dashboard after a few reviews (streak, due count, level bars) |
| `tutor.png` | The AI tutor answering in TEACH or QUIZ mode, with furigana |
| `kanji.png` | The Kanji browser with one kanji's detail window open |

Until these files exist, the images in the README show as broken links.
